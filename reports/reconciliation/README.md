## Как работать с результатом

1. Откройте `RBBB-Import-Reconciliation-2026-07-12.xlsx` из каталога `outputs/rbbb-reconciliation`.
2. Начните с `Summary`, затем последовательно обработайте `RBI Match Conflicts`, `RBI Team Conflicts` и `RBI Not Found`.
3. Заполняйте только жёлтые поля `Decision`, `Approved Project ID` и `Review Comment`.
4. Для Кенжекулова общий marker не использовать как самостоятельное доказательство.
5. До завершения ручных решений не выполнять apply/import, не создавать выплаты и не изменять live-БД.
