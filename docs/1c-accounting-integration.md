# Обмен бухгалтерии HUB с 1С

HUB поддерживает два режима обмена, которые можно включать одновременно:

1. **Push (рекомендуется):** 1С отправляет изменённые документы в HUB после проведения или по регламентному заданию.
2. **Pull:** бухгалтер нажимает «Синхронизировать 1С», HUB вызывает опубликованный HTTP-сервис 1С и получает пакет изменений.

Стандартный OData 1С подходит как транспорт, но имена документов и реквизитов зависят от конфигурации. Поэтому для рабочей базы рекомендуется небольшой HTTP-сервис или расширение 1С, возвращающее единый JSON ниже. Изменять типовую конфигурацию не обязательно.

## Адрес приёма HUB

`POST https://hub.rbpartners.kz/api/1c/sync`

Заголовки:

```http
Content-Type: application/json
X-Hub-1C-Key: <ONEC_SYNC_SECRET>
```

Администратор может создать ключ непосредственно в бухгалтерском кабинете кнопкой «Создать ключ 1С». HUB хранит только SHA-256 хеш; исходный ключ показывается один раз.

## Сопоставление с проектами

1. Если передан `projectId`, используется точный ID HUB.
2. Иначе HUB ищет нормализованный номер договора.
3. Если номер повторяется, HUB уточняет проект по БИН заказчика и нашей компании.
4. Неоднозначные и ненайденные строки считаются по причине и показываются бухгалтерии в блоке «Разобрать». После исправления договора/БИН повторная синхронизация забирает их из 1С заново.

Повторная отправка одного `externalId` обновляет существующую запись и не создаёт дубль.

## Переменные окружения Vercel

- `ONEC_SYNC_SECRET` — альтернативный секрет push-обмена через Vercel. Обычно вместо него используется ключ, созданный администратором в HUB.
- `ONEC_SYNC_URL` — URL HTTP-сервиса 1С для ручного pull (необязательно).
- `ONEC_USERNAME`, `ONEC_PASSWORD` — Basic Auth для pull (необязательно).
- `ONEC_BEARER_TOKEN` — Bearer вместо Basic Auth (необязательно).
- `ONEC_SYNC_METHOD` — `GET` по умолчанию.

Секреты хранятся только в Vercel и никогда не передаются в браузер.

## Минимальная проверка

```bash
curl -X POST "https://hub.rbpartners.kz/api/1c/sync" \
  -H "Content-Type: application/json" \
  -H "X-Hub-1C-Key: $ONEC_SYNC_SECRET" \
  --data @onec-test-payload.json
```

Успешный ответ содержит `received`, `matched`, `unmatchedCount` и `updatedProjects`.
